# Security policy

## Supported versions

Security fixes are released for the latest version of Svifa.

## Reporting a vulnerability

Report it privately through GitHub: open the [Security tab](https://github.com/arcwrightstudio/svifa/security) and choose **Report a vulnerability**. Please do not
open a public issue.

Describe what an attacker could do and how to reproduce it. You will get a reply within a few days and be kept informed until a
fix is released. Reporters are credited in the release notes unless they ask not to be.
